Fake Bank Security Alert: The Locked Account Trap

A fictional investigation into a banking warning that uses fear, urgency and a fake verification page to push visitors into revealing sensitive information.

EDITORIAL NOTE
This is a fictional demonstration case created for the Scam Alert website. The bank, message and interface shown below are not presented as real-world allegations.

The pressure comes before the proof

A convincing security warning does not need to contain sophisticated malware to be dangerous. A familiar-looking alert can simply make the visitor afraid that an account will be locked, then offer one obvious button to “fix” the problem.

The strongest warning sign is the combination of an unexpected message, a deadline and a request to verify information through the supplied link. A legitimate security concern should still be independently verifiable through the bank’s official app or website.

What we would verify

We would inspect the domain, compare the branding with the real institution, follow redirects without entering credentials, and check whether the page requests information that should never be collected through an unsolicited message.
